# Данные

Исходные данные предоставлены образовательной платформой в рамках курса и в репозиторий не входят.

Чтобы воспроизвести анализ, положите данные в эту папку в следующей структуре:

```
data/
├── orders/
│   └── 2024-03-01/
│       └── Алексей Саксофонов/
│           ├── orders.csv          # order_id, product_id, quantity
│           └── order_status.csv    # order_id, client_id, status
├── products/
│   └── AV-процессор/
│       └── products.csv            # id, name, price
└── usd_rate.txt                    # дата,курс,валюта
```

- Название папки внутри `orders/` — дата записи (`гггг-мм-дд`), вложенная папка — имя менеджера.
- Название папки внутри `products/` — категория товара.
- `name` в `products.csv` имеет вид `Бренд, Модель`; `price` указана в долларах США.

При запуске ноутбук сохранит собранные таблицы в `data/processed/`.
